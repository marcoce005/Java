# Wrapper Class

 - provides a way to use primitive data types as reference data types

 - reference data types contain useful methods 

 - can be used with collections (ex. ArrayList)

| **Primitive** | **Wrapper** |
|------------|----------|
| `boolean` | `Boolean` |
| `char` | `Character` |
| `int` | `Integer` |
| `double` | `Double` |

Primitive value are faster than the wrapped one. 

### Autoboxing
The automatic conversion that the Java compiler makes between the primitive types and their corresponding object wrapper classes. 

### Unboxing
The reverse of autoboxing. Automatic conversion of wrapper claaa to primitive.
